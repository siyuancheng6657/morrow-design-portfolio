# MORROW · 日常之间

家居生活方式商城应聘作品。围绕「商城设计、系统 UI、线下宣传、商城编辑维护」四项岗位职责，组织为一个可演示的完整项目：商城前台、运营后台、活动海报与作品说明。

这是独立概念作品。品牌、商品参数、价格、库存与订单均为演示内容；项目使用浏览器本地存储；本机网站服务提供页面和素材，未接入业务后端，不产生真实支付或发货。

## 本机网站（已部署）

直接访问 **http://127.0.0.1:5188/**。后台为 **http://127.0.0.1:5188/#admin**，作品说明为 **http://127.0.0.1:5188/#portfolio**。

桌面有 **MORROW 商城** 快捷方式：双击会自动检查并启动后台网站，然后打开浏览器。也可以双击本文件夹的 **打开商城.vbs**，无需打开命令窗口。重新启动电脑后，再双击该入口即可；没有设置开机自动启动。

- **停止网站.cmd**：停止此作品的后台进程。
- **启动网站.cmd**：备用入口，显示启动结果与错误。
- **查看网站状态.cmd**：检查是否已经启动。
- 关闭浏览器或启动窗口后，网站继续运行；重复启动沿用同一进程。
- 网站仅监听本机 127.0.0.1:5188，没有修改防火墙。请固定使用这个地址；localhost 和 file:// 使用不同的浏览器存储。
- 页面位于 `dist`，运行脚本仅依赖已有 Node.js，不会在每次启动时安装依赖或重新构建。源码更新后执行 `pnpm build` 即可更新页面。
- 运行状态和日志在 `.local`，不属于交付源码。停止入口会核对当前进程和项目路径，不会根据过期PID终止其他程序。

已验证 Windows PowerShell 5.1、中文路径、不同工作目录下的CMD冷启动（退出码0）、停止后端口释放、桌面入口相同目标的WSH冷启动，以及再次运行仍为同一进程。HTTP 22项检查通过，商城/后台实际访问正常，之前的浏览器示例订单仍保留。桌面入口的已解析目标执行通过；未通过工具直接点击桌面图标。Windows整机重启未做。

## 直接打开作品

先看 `MORROW-作品集.pdf`：5页精简作品集，适合直接发给招聘方。面试现场再打开下面的网页，演示真实交互。

收到完整交付文件后，双击 **`dist/打开作品.html`**。无需安装 Node.js 或开发工具。

- 必须保留并一起复制整个 `dist` 文件夹；其中的商品图片、海报等都是本地资源。
- 建议使用当前版本的 Edge、Chrome、Firefox 或 Safari 查看。具体已验证的浏览器、尺寸与结果以交付测试记录为准。
- 操作数据保存在当前浏览器的 `localStorage`。更换浏览器、清理网站数据或改变打开位置后，可能看到一份新的演示数据；隐私模式也可能不保留数据。
- 演示订单已预填示例收件信息，可直接体验，不需要输入真实个人信息。

## 建议演示顺序

1. **商城前台**：展示首屏、分类、关键词搜索与商品详情；加入购物袋、修改数量，再生成演示订单并下载订单回执。
2. **运营维护**：从页脚进入运营后台，修改商品内容或上下架状态，再返回商城检查变化；展示首页活动内容维护、订单记录和商品目录 CSV 导出。
3. **平面设计**：进入作品说明查看活动海报，打开海报源文件与制作说明，说明线上与线下视觉如何保持一致。
4. **适配与细节**：查看窄屏布局，演示搜索无结果、购物袋为空或库存不足等状态。面试讲解可参考 `docs/面试讲解稿.md`。

## 源码运行

源码使用 **React + Vite**。建议开发环境为 **Node.js 20.19 或以上版本**，并已安装 pnpm。以下命令全部在 **`MORROW应聘作品` 根目录**执行，避免在其他项目中误运行。

```powershell
Set-Location -LiteralPath 'C:\Users\程思源\Desktop\MORROW应聘作品'
pnpm install
pnpm dev
```

浏览器打开终端显示的本地地址。重新构建交付文件时，在同一目录执行：

```powershell
pnpm build
```

构建脚本会生成 `dist`，并制作可直接打开的离线入口。开发服务与离线文件的浏览器存储相互独立。
