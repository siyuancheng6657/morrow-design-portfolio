# MORROW 设计依据

完整主屏依据 store-concept.png；下游商品和品牌段落依据 collection-concept.png；后台依据 admin-concept.png。图像生成概念由执行方审阅采用，用户确认家居生活方式方向。

色彩：暖纸 #f7f5f0、主文字/按钮森林绿 #263d34、次级文字 #777970、分割线 #dedfd7、活动陶土 #ac664b。照片不添加色彩蒙层。

字体：中文展示字采用本地 Noto Serif SC 子集 MorrowSerif 500，拉丁品牌 Georgia；操作区采用 Noto Sans SC 子集 MorrowSans 400，并保留系统回退字体。两款字体嵌入 CSS，离线不发起字体请求。标题 78–88px，区块标题 38px，正文 15–17px，控件 14px，辅助字 12px。移动端标题 48px。

布局：顶部 34px 通栏活动公告、72px 页眉；桌面主视觉 42% 文案 + 58% 照片，约 560px 高；三项服务横栏；四列开放商品网格；品牌故事 50/50 图文拼接；深绿页脚。桌面边距 6%，移动端 22px。

组件：方形主按钮、下划线文字链接、统一 1.5–1.7px 线性图标、原生 dialog 详情/购物袋/结账弹窗、商品图片正方形、无外框商品列表。后台与商城共用商品状态。商品图与参考中的造型细节以独立生成的最终素材为准；不把概念里的微小照片裁剪成生产素材。

首屏文案锁定：MORROW / 日常之间；首页 / 精选好物 / 生活灵感 / 关于我们；秋日上新 · 把喜欢的日常带回家；让日常，慢下来。；从一只杯子、一盏灯开始，为生活留一点温柔的空白。；探索秋日精选 / 浏览全部好物。服务承诺为概念商城展示文案，不代表实际销售服务。

必要功能扩展：搜索面板、商品详情、购物袋、演示结账、订单回执、作品说明页、活动海报展示与下载、后台商品及内容编辑；在既定视觉体系内实现。移动端两列商品、上下堆叠主视觉和品牌故事，主导航保留可滚动区域。所有交易与数据均为本浏览器演示。


## 最终视觉复核

2026-09-10，使用 view_image 同轮查看完整设计概念、最新 Edge 页面截图、手机截图及后台截图。主屏以概念原生 1487×1058 尺寸比较，后台在1440×1000与390×844比较。

| 对照点 | 最终处理 |
| --- | --- |
| 首屏文案 | 品牌、四项导航、主标题、介绍、两个CTA均保留；无新增标题前徽标。底部增加概念作品说明属于真实用途标记。 |
| 首屏布局 | 42/58图文比例、560px主视觉、6%页边距；已修正导航居中与按钮尺寸。 |

| 色彩 | 保持暖纸#f7f5f0、森林绿#263d34；图片无有色蒙层。海报沿用同系纸色和陶土强调色。 |
| 商品与下游布局 | 四列开放陈列、正方形图框、50/50品牌故事拼接、深绿页脚；手机切换为两列与上下叠放。 |
