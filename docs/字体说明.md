# MORROW 本地字体说明

为减少不同设备系统字体造成的版式差异，作品附带两份 WOFF2 字体子集。它们由本机已有的 Noto 简体中文字体生成，仍按 SIL Open Font License 1.1 分发；这不是自行设计的新字体。

## 交付文件

| 文件 | 内部字体族名 | 字重 | 大小 |
| --- | --- | --- | --- |
| `public/fonts/morrow-serif.woff2` | `MorrowSerif` | 500，静态 | 146,400 bytes，约 143 KiB |
| `public/fonts/morrow-sans.woff2` | `MorrowSans` | 400，静态 | 110,728 bytes，约 108 KiB |
| `public/fonts/OFL.txt` | 官方许可原文 | — | 与字体一起分发 |
| `public/fonts/COPYRIGHT.txt` | 原版权与许可元信息摘录 | — | 与字体一起分发 |
| `public/fonts/font-subset-record.json` | 生成范围、尺寸、字符数与 SHA-256 | — | 复核记录 |

宋体子集用于标题，无衬线子集用于正文和操作区域。两份字体都将可变字体实例化为单一字重，以缩小本地展示包。

## 来源与制作方式

- 宋体来源：`C:\Windows\Fonts\NotoSerifSC-VF.ttf`，保留原字体版权 `© 2017-2023 Adobe (http://www.adobe.com/).`。
- 无衬线来源：`C:\Windows\Fonts\NotoSansSC-VF.ttf`，保留原字体版权 `© 2014-2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'.`。
- 使用 fontTools 4.64.0 和 Brotli 1.2.0 生成子集，随后实例化字重、输出 WOFF2。工具依赖通过 PyPI 官方索引安装到临时专用目录，没有修改系统中的原字体。
- 修改版本的字体族名分别改为 `MorrowSerif`、`MorrowSans`；原版权、许可说明与许可链接保留在字体的 `name` 元信息中，并另附可读文本。
- `OFL.txt` 从 [Noto CJK 官方仓库的 SIL OFL 1.1 原文](https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/LICENSE) 下载，未改写原文。

## 字符范围与后续维护

2026-09-10 生成时，扫描 `src` 下全部 `.jsx` 与 `.js` 文件，收录其中出现的字符，并补充基本拉丁字符和常用中文标点。两份最终子集均包含 **687 个 Unicode 字符映射、1,099 个字形**；映射之外的字形用于字体排版和关联处理。扫描文件清单见 `font-subset-record.json`。

编辑后台时新输入的汉字，或后续新增文案中的字符，可能不在子集中。页面应保留中文系统字体作为 fallback，让浏览器自动显示未收录字符；扩大固定文案范围后，可重新生成子集。子集本身不提供所有汉字，也不包含多个可切换字重。

字体的原文件保存在本地，并以 data URL 内嵌于 src/fontfaces.css，以避免离线字体的跨域加载限制。CSS 已配置 `font-display: swap`，并为宋体、无衬线各自设置合适的系统回退字体。整体复制 `dist` 文件夹时，字体目录和许可文件必须随其他资源一起保留。

## 已完成核验

生成后使用 fontTools 重新打开两份 WOFF2，确认字体可以解析、可变轴表已移除、内部名字与 500 / 400 字重正确、原版权和许可元信息仍存在。所有请求字符均在原字体及最终子集内，没有丢失映射；每个文件均小于 400 KiB。源文件与交付文件的 SHA-256 已记录。

以上是字体文件结构核验。页面上的实际字重、换行、加载与设备表现，需要结合最终浏览器测试记录查看，不将结构核验表述为跨浏览器渲染验收。
