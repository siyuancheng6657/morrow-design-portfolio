# MORROW · 三分钟面试讲解稿

使用前，把与个人实际参与情况不符的表述改成真实说明。这个项目是独立概念作品，商品图片采用 AI 辅助生成；它用于展示作品能力，不替代个人工作经历或工具熟练度证明。海报源文件的具体制作方式请按《海报制作说明》介绍。

## 0:00—0:35｜项目定位与视觉

打开商城首屏。

“这是一份家居生活方式商城概念作品，品牌叫 MORROW，中文是‘日常之间’。我把岗位要求中的商城设计、系统 UI、线下海报和商城维护放进同一个项目，让面试时能从设计看到实际使用流程。

视觉以暖纸色、森林绿和自然材质图片为主。首屏先传达生活氛围，主要按钮引导到商品，下面再提供服务信息与分类，帮助用户从‘喜欢这个风格’走到‘找到一件商品’。”

## 0:35—1:25｜商城交互与页面实现

点击「餐厨器皿」，打开搜索输入「陶瓷」，查看「晨光手作陶瓷杯」详情，加入购物袋并生成演示订单。

“这里可以按类别和关键词找商品，在详情里查看材质、规格、库存，再调整数量并加入购物袋。购物袋会计算金额和运费，满 199 元包邮。提交演示订单后，会记录订单、扣减本地库存，并提供订单回执下载。

除了正常路径，我也处理了搜索无结果、空购物袋、售罄、库存不足以及商品下架后的结账限制。页面使用 React 组件和 CSS 响应式布局，数据存在当前浏览器，只演示流程，不产生真实交易。”

## 1:25—2:05｜运营后台与编辑维护

从页脚进入「运营后台」。修改一件商品的名称或价格并保存，返回前台展示变化；再演示一次下架与恢复上架。时间允许时修改首页活动文案。

“后台与商城共用同一份商品数据。运营编辑内容后，前台会随之更新；下架商品不会继续出现在商城列表中。后台还可以新增商品、筛选和导出商品目录，并查看刚才的演示订单。

演示时我会注意保存反馈、输入规则、库存和上下架状态，而不是只展示静态界面。”

## 2:05—2:35｜活动海报与素材来源

进入作品说明，查看活动海报，再打开 `design/poster-sources` 与《海报制作说明》。

“海报延续商城的色彩和自然材质方向，让同一个活动在线上页面、线下 A3 海报和社交传播尺寸中保持一致。我会展示实际提供的源文件、文字层与图片素材如何组织，以及尺寸和导出文件。

商品与场景图片有 AI 辅助；PSD 由程序写入，含独立图层和文字层，经过结构解析核验，但没有在 Photoshop 中实机验收。具体编辑范围按制作说明介绍，不能仅凭一个 PSD 文件证明 Photoshop 熟练度。”

## 2:35—3:00｜设备适配与完成范围

切换至窄屏，展示导航、商品列表和购物袋；如已提供实测截图或记录，可同时打开。

“页面考虑了桌面与手机的内容排列、文字可读性和操作空间。兼容性我会按实际测试记录说明浏览器和尺寸，不把未测试的设备说成已通过。

这份作品的交付范围是一个可离线展示的前端项目，包括商城、后台维护演示、活动海报和说明文件。完整 `dist` 文件夹可以直接复制并打开，便于面试官复核。”

## 演示前准备

- 在计划使用的浏览器打开 `dist/打开作品.html`，并保留完整 `dist` 文件夹。
- 先检查当前演示数据和库存，避免之前的操作影响讲解；结账使用预填的示例信息。
- 打开海报制作说明，核对 PSD 来源与可编辑内容后再介绍。
- 确认最终测试记录中实际完成的浏览器和尺寸；没有记录的部分表述为待验证。
- 若被问到工作年限、独立完成范围或 Photoshop 熟练度，按个人真实情况回答。
